# KeyTone 键响匣（幽灵版）· v0.8

**KeyTone 键响匣 · 全局键盘音效程序**

功能：全局监听键盘，三种模式 F12 一键切换——① 按键音效（每个按键绑定独立音效）② 音符弹琴（任意按键发电子琴音，键盘即钢琴）③ 预制旋律（内置乐谱，按音乐盒方式推进播放）。支持打断式播放（新音立即替换旧音）、音量/音调实时调节、单实例防重复，已打包单文件 exe 免 Python 环境，双击即用。

效果：装上它，打字变成演奏，每一次敲击都成曲——办公、写代码、聊天时随手敲两下，单调的键盘声瞬间变成自己的背景音乐，沉浸到停不下来。

> 详细设计文档见 [DOCS.md](DOCS.md)（架构设计、关键机制、排障指南）。

全局键盘按键音效程序。**开启后找不到关闭的地方**：无窗口、无控制台、无托盘图标、无任何提示、无退出快捷键。

内置三种模式，按 `F12` 循环切换：**按键音效**（默认）→ **音符弹琴**（任意按键发电子琴音）→ **预制旋律**（不管按哪个键，都按内置乐谱推进播放，像音乐盒）。

**打断式播放**：每次按键音都立即打断正在播放的前一个音（不叠加、不糊音）。

## 启动

1. 依赖安装（首次）：`pip install pynput pygame`
2. 确认 `sounds/` 下存在对应 wav（可用 `generate_sounds.py` 生成测试音）
3. 启动方式任选：
   - **打包版**：双击 `dist/KeyTone.exe`（推荐，无需 Python 环境）
   - 源码版：双击 `start_ghost.vbs`（无窗口），或命令行 `pythonw main.py`

启动成功会弹自定义轻量 toast「已启动，后台静默运行中」（tkinter 进程内绘制，右下角自动消失，几十毫秒响应，无系统弹窗）；若已有实例在运行，弹 toast「已在运行，请勿重复启动」后自动退出。
> 无需管理员权限：pynput 低级键盘钩子普通权限即可全局监听，唯一限制是监听不到"以管理员身份运行"的窗口内的按键（UAC 隔离）。

## 停止

没有任何退出方式，只能通过任务管理器结束进程：
`Ctrl+Shift+Esc` → 在"进程"中找到 `pythonw.exe`（或 `python.exe`）→ 结束任务。

## 静默调节（运行中生效，无任何提示）

| 按键 | 作用 |
|---|---|
| `=` / `-` | 音量 ±0.05（0~1） |
| `]` / `[` | 音调 ±0.05（0.5~2.0） |

## 音符弹琴模式

- 按 **F12** 切换：按键音效模式 ↔ 音符弹琴模式（切换弹 toast 提示）
- 音符模式下**任意按键**按下都会发声：主键盘区按行映射音高（数字行最高，字母行依次，ZXCV 行最低；行内左低右高），特殊键（空格/回车/Shift 等）排低音区，F1~F11 排最高音区
- 音色为程序内实时合成的电子琴音（正弦 + 泛音 + 指数衰减），不依赖 wav 文件；首次按某键合成后缓存，之后零延迟
- `=`/`-` 音量、`]`/`[` 音调调节在三种模式下都生效

## 预制旋律模式

- **F12 循环切换**三种模式：按键音效 → 音符弹琴 → 预制旋律 → 按键音效（切换弹 toast 提示）
- 不管按哪个键，都按内置乐谱顺序播放下一个音，到尾循环（音乐盒效果）；默认内置《小星星》
- 自定义乐谱：编辑 `main.py` 的 `MELODY` 常量——简谱 1~7（do~si），`'` 表示高八度（如 `5'`）、`.` 表示低八度（如 `5.`）、`0` 休止（无声但推进）、空格仅作分组
- 音色与音符弹琴模式共享（合成电子琴音 + 缓存），音量/音调调节同样生效

## 排障

- 日志写入同目录 `keytone.log`（音效加载失败、启动异常等），可随时删除
- 音效文件缺失时该按键静默无声音，不崩溃
